Frequently Asked Questions (FAQ)

What makes BoltDrop ShareP2P different from Google Drive or WeTransfer?

Traditional cloud providers force you to upload your files to their remote servers before generating a download link. BoltDrop uses native WebRTC peer-to-peer data channels to stream files directly between two devices in real-time, eliminating file size limits and cloud privacy risks.

How does Wi-Fi Local Share work?

When two or more devices are on the same Wi-Fi network or local router, BoltDrop automatically groups them on the radar screen based on shared public network IP pairing for instant tap-to-send discovery.

Are there any file size limits on BoltDrop?

There are zero file size limits! Whether you are sending a 10MB PDF document or a 50GB video file, BoltDrop streams the data continuously in real-time.
